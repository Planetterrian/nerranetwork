Models & Agents

NVIDIA just released an open frontier model built from the ground up for long-running agents.

What You Need to Know: NVIDIA released Nemotron 3 Ultra, an open model explicitly designed for persistent agent workloads. DeepSeek previewed V4 series MoE models that support million-token contexts with major efficiency gains. Anthropic advanced its robodog programming experiments while OpenAI shared new alignment training results that show cross-domain transfer.

Top Story

NVIDIA released Nemotron 3 Ultra, an open frontier model positioned for long-running AI agents. The model targets sustained agent operation rather than single-turn chat, addressing a gap where most open models still struggle with extended tool-use loops and state management. Builders working on autonomous workflows now have a high-capability open option that can be self-hosted or fine-tuned without closed-model restrictions. Early positioning suggests it competes directly with the top closed models on agent-relevant tasks while remaining fully open weights. Watch for integration examples with existing agent frameworks and any announced context-length or tool-calling benchmarks in the coming weeks. Source: Google News

Model Updates

DeepSeek-V4: Towards Highly Efficient Million-Token Context Intelligence: arXiv

DeepSeek previewed the V4 series with two MoE models: V4-Pro (1.6T total, 49B active) and V4-Flash (284B total, 13B active), both supporting 1M token context. The models use hybrid Compressed Sparse Attention plus Heavily Compressed Attention, Manifold-Constrained Hyper-Connections, and the Muon optimizer after pre-training on over 32T tokens. V4-Pro-Max reportedly sets a new open-model reasoning bar while cutting inference FLOPs to 27% and KV cache to 10% of the prior version at million-token lengths. Checkpoints are already on Hugging Face. Builders running long-horizon agents should test the 1M context mode this week to see where the efficiency gains actually appear in practice. Source: arxiv.org

Liquid AI Introduces LFM2.5-Embedding-350M and LFM2.5-ColBERT-350M: MarkTechPost

Liquid AI released two 350M parameter retriever models: a dense bi-encoder and a ColBERT late-interaction variant for fast multilingual search. The pair targets edge deployment across 11 languages with a focus on low-latency retrieval. The models combine dense and late-interaction approaches to balance speed and accuracy on resource-constrained hardware. Developers building on-device RAG or search features now have a compact, multilingual option that avoids larger cloud models. Source: marktechpost.com

Agent & Tool Developments

Watch the robodogs in action in our first Project Fetch experiment: @AnthropicAI

Anthropic shared video of its first Project Fetch experiment testing Claude’s ability to program robodogs. In Phase 2, Opus 4.7 completed the programming task roughly 20x faster than last year’s best human team using Opus 4.1, though the physical robot still failed to fetch a beach ball. The work explores how frontier models handle real-world robotics code under realistic constraints. Teams building physical or simulated agents should review the accompanying Frontier Red Team blog for details on failure modes and iteration speed. Source: x.com

SEP2 brings Gemini Enterprise agents into managed threat monitoring: TechInformed

SEP2 integrated Gemini Enterprise agents into its managed threat monitoring platform for security operations. The agents now participate in live detection and response workflows inside customer environments. This marks another production deployment of frontier models inside regulated security stacks. Security teams evaluating agentic SOC tooling can request early access to see how the Gemini agents handle alert triage and escalation. Source: Google News

Fabrix.ai demonstrates production-grade agentic operations at Cisco Live: SiliconANGLE

Fabrix.ai showed live production-grade agentic operations running at Cisco Live. The demonstration focused on real enterprise workflows rather than prototypes. Attendees saw agents handling multi-step network and security tasks with measurable reliability. Operators looking for battle-tested agent platforms should examine the demo recordings for concrete latency and success-rate numbers. Source: Google News

Qualcomm CEO Cristiano Amon on the new world of AI agents: CNBC

Qualcomm’s CEO discussed the shift toward on-device and edge AI agents as the next major platform change. The comments emphasize hardware-level support for persistent agent execution rather than cloud-only models. Device makers and edge developers now have clearer signals on where silicon vendors are investing. Watch for upcoming Snapdragon platforms that expose agent-specific accelerators and memory architectures. Source: Google News

Practical & Community

More info on Datasette Apps live demo and uv one-liners: Simon Willison (AI builder)

Simon Willison published full details on Datasette Apps, including the live demo and one-line uv commands for local testing. The system gives HTML+JS apps a JSON API plus full relational database backend, extending the Claude Artifacts pattern with persistent structured storage. Developers who want artifact-style rapid prototyping with real data persistence can install and run the examples immediately. Source: x.com

e2e-assure introduces Cumulo, the U.K.’s only sovereign, AI-driven, zero-day SOC platform: AI News

e2e-assure launched an updated Cumulo platform that uses customer-dedicated AI models and digital twins for zero-day threat detection across IT and OT. The system is positioned as the U.K.’s only sovereign AI-first SOC offering and directly addresses GCHQ’s AI Cyber Shield call. Security teams needing air-gapped or regulated deployments now have a concrete sovereign option to evaluate. Source: artificialintelligence-news.com

Under the Hood: Million-Token Context in MoE Models

Everyone talks about “million-token context” as if it is simply a bigger KV cache. In practice, it requires coordinated changes across attention, residual connections, and optimizer to keep both memory and compute manageable. DeepSeek-V4’s hybrid CSA + HCA approach compresses the attention computation so that a 1M-token forward pass uses only 27% of the FLOPs and 10% of the KV cache of the prior version. The Manifold-Constrained Hyper-Connections further stabilize training at this scale by replacing standard residuals with learned manifold projections. At inference time the savings only appear once context exceeds roughly 128k tokens; below that the overhead of the compressed paths can actually slow things down. Teams should therefore profile both short and long contexts before committing to these architectures. The practical decision rule is simple: if your typical agent session stays under 100k tokens, the new mechanisms add complexity with little payoff; once you routinely exceed that threshold, the efficiency gains become decisive.

Things to Try This Week

  • Test DeepSeek-V4-Flash or V4-Pro on Hugging Face for any workflow that already pushes past 128k tokens and measure actual KV cache and latency savings.
  • Run the Datasette Apps one-liners from Simon Willison’s post to prototype a small HTML+JS app backed by a real relational database in under five minutes.
  • Review Anthropic’s Project Fetch Phase 2 blog for concrete numbers on how much faster frontier models now iterate on robotics code compared with human teams.
  • Experiment with Liquid AI’s 350M ColBERT retriever on edge hardware if you need fast multilingual search without calling larger cloud models.

On the Horizon

  • More inference providers are expected to add GLM 5.2 support following Simon Willison’s request to Groq and Cerebras.
  • Additional Phase 2 Project Fetch results from Anthropic will likely include more detailed failure analysis and iteration metrics.
  • Further details on Nemotron 3 Ultra agent benchmarks are anticipated in the coming weeks.
  • OpenAI’s cross-domain alignment work may receive additional evaluation releases or code artifacts.

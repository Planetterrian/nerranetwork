Together Compiler lets agents re-optimize inference on the fly and delivers up to 2.6 times higher throughput.

By Patrick November 05, 2026 Ep 225 12 min read Listen to podcast Watch on YouTube
Listen in

What You Need to Know: OpenAI released GPT-Image-2.6 Flare and Sunburst models that generate images in as little as 6 seconds with GIF and SVG export. Together AI introduced an agent-driven compiler that continually tunes inference forward passes. New arXiv work on small-model long-context memory and strategic clarification in dialogue adds concrete benchmarks and methods builders can test immediately.

Top Story

Together AI released Together Compiler, an agent-driven loop that keeps re-optimizing the inference forward pass as traffic shifts. It beat the best InferenceX configurations by up to 2.6x TPS in under 24 hours per model. The system treats inference optimization as a continual compilation task rather than a one-time static pass. Developers running variable workloads on open models can now let lightweight agents monitor token throughput and rewrite kernels on the fly without manual retuning. The approach is model-agnostic and works on existing checkpoints. Watch for open-source releases of the compiler loop and integration guides for vLLM and TensorRT-LLM backends. Source: marktechpost.com

Model Updates

OpenAI Launches GPT-Image-2.6 Flare and Sunburst: Adds GIFs, SVG Export and 6-Second API Generation — MarkTechPost

OpenAI released Images 2.6 and the GPT-Image-2.6 Flare and Sunburst API models. Flare generates images in as little as 6 seconds. Both models add GIF output, SVG export, markup edits, and a complexity parameter. The updates target developers who need faster iteration on visual assets inside agent loops or design tools. Source: marktechpost.com

Google AI Research Releases Agile Deliberation Framework for Gray-Area Image Classifiers — MarkTechPost

Google Research released Agile Deliberation, a human-in-the-loop framework that helps users define subjective visual concepts through borderline images. In 18 live sessions it lifted Gemini-based classifier F1 by 10.5 points over zero-shot. The method surfaces ambiguous examples for human adjudication rather than forcing binary labels early. Source: marktechpost.com

SRRM: A Retrieval-Reconstruction Benchmark for Evaluating Long-Context Memory in Small Language Models — arXiv NLP

SRRM jointly evaluates targeted retrieval and global information reconstruction on synthetic datasets with 10 to 100 factual statements. Qwen2.5-1.5B reached 86.7% retrieval accuracy and 45.7% reconstruction while the 3B variant scored 72.2% and 18.5%. Reconstruction performance fell faster than retrieval as context grew, showing retrieval-only metrics miss memory loss in small models. Source: arxiv.org

When to Ask, When to Answer: Strategic Clarification for Ambiguous Reference Resolution in Dialogue — arXiv NLP

The work introduces BACE, a belief-aware critic that tracks epistemic status on top of a frozen LM. BACE chooses the optimal number of clarifying questions more consistently than GRPO or ArCHer on the SIMMC 2.1 reference game. The method records how many questions each ambiguous referent needs and penalizes premature answers. Source: arxiv.org

Agent & Tool Developments

Prospective Memory for Proactive LLM Agents — arXiv NLP

Pro-Memory separates maintaining future intentions from deciding when to realize them. It preserves pending objectives with supporting evidence, assesses new observations against activation conditions, and updates states after actions complete. Experiments on delayed-intention and open-ended assistance benchmarks showed consistent gains across multiple LLM backbones while limiting unnecessary interventions. Source: arxiv.org

Cognitive Bias Signatures in Search-Equipped LLM Agents: A Stage-Resolved Analysis — arXiv NLP

The study ran 10 models across 1,000 synthetic search worlds and tracked queries, retrieved documents, openings, and final answers. Final answers proved more sensitive to initial evidence order during active search than when all evidence arrived at once. Dead-end histories reduced strategy switching beyond what context length alone predicts. Source: arxiv.org

Practical & Community

Rewrite, Then Veto: Rewriter-Agnostic Edit Gating for LLM-Based Post-OCR Correction — arXiv NLP

EditVeto places a 0.6B-parameter gate after a full-context LLM rewrite and keeps or reverts each aligned block. The gate improved all five rewriters tested on HIPE-OCRepair-2026, lowering weighted cMER by 0.0026-0.0044. It works on rewriters unseen during training and raises preference scores by 0.15-0.25. Source: arxiv.org

RAGCompass: Generalizable Retriever Routing via Reranking — arXiv NLP

RAGCompass fine-tunes a reranker on the answer each evidence set produces and adds a small comparison head. It improved answer F1 by 28% relative to the best fixed retriever and kept most gains under unseen corpora, retrievers, or readers. The router reads passage sets directly, avoiding query-only feature limitations. Source: arxiv.org

Editing Large Language Models with Geometry-Aware Regularization — arXiv NLP

GEdit uses a low-rank plus diagonal factor model to protect a core knowledge subspace while relaxing constraints on hard edits. On GPT-J and LLaMA-3-8B it outperformed baselines in both editing success and knowledge preservation across up to 10,000 sequential updates. The method requires no retraining of the base model. Source: arxiv.org

Under the Hood: Recurrent Depth in Transformers

Recurrent depth re-uses the same transformer layers in a loop instead of stacking new ones, giving a small model more sequential compute steps without extra parameters. The core mechanism is simple: each layer receives both the current token representation and a recurrent state carried from its own previous pass, exactly as described in the Block-Recurrent Transformer paper. This produces linear complexity in sequence length while still allowing the model to refine its internal state over multiple iterations at inference time. The tradeoff appears clearly in the Griffin work: Hawk and Griffin match Llama-2 performance after training on six times fewer tokens, yet the recurrent state must be sized and initialized carefully or the model loses the ability to extrapolate beyond training lengths. Relaxed Recursive Transformers add depth-wise LoRA modules to loosen the strict parameter-sharing constraint, recovering most of the original model's accuracy at roughly one-quarter the parameter count. RecurrentGemma demonstrates the practical payoff: the 2B and 9B variants reach comparable downstream scores to standard Gemma checkpoints despite fewer training tokens, and they run with fixed memory cost on long sequences. The practical rule is to prefer recurrent depth when parameter count or training data is the binding constraint and to fall back to deeper feed-forward stacks when maximum single-pass quality on short contexts matters most. Source: arxiv.org

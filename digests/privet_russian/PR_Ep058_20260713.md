### Word of the Day
**Собака** (so-BA-ka) — dog
Example sentence: Моя собака любит бегать. (My dog loves to run.)  
Memory hook: Imagine a Siberian husky barking “so-BA-ka!” like it’s calling its own name.  
Repeat after me: So-BA-ka… so-BA-ka… now faster: собака!
- **Собака** (so-BA-ka) — dog
  Example sentence: Собака играет во дворе.  
  Example translation: The dog is playing in the yard.  
  Memory hook: Sounds like “so bark-a” — perfect for a barking dog!

- **Медведь** (myed-VYED’) — bear
  Example sentence: Большой медведь спит в лесу.  
  Example translation: The big bear sleeps in the forest.  
  Memory hook: Think “my head” with a “vyed” growl at the end — a bear with a big head!

- **Птица** (PTI-tsa) — bird
  Example sentence: Птица поёт на дереве.  
  Example translation: The bird sings in the tree.  
  Memory hook: “Ptee-tsa” flits like a tweet from a tiny bird.

- **Рыба** (RY-ba) — fish
  Example sentence: Рыба плавает в воде.  
  Example translation: The fish swims in the water.  
  Memory hook: “Ree-ba” rhymes with “reefer” — a fish in the reef!

- **Лошадь** (LO-shad’) — horse
  Example sentence: Лошадь бежит быстро.  
  Example translation: The horse runs fast.  
  Memory hook: “Lo-shad” sounds like “low shed” where a horse might hide.

- **Мышь** (MYSH) — mouse
  Example sentence: Маленькая мышь ест сыр.  
  Example translation: The little mouse eats cheese.  
  Memory hook: Remember мышь from before? It still means mouse — tiny and quick!

- **Кот** (kot) — tomcat / male cat
  Example sentence: Кот сидит на окне.  
  Example translation: The cat sits on the window.  
  Memory hook: “Kot” is short and cozy, like a cat curled up.

- **Заяц** (ZA-yats) — hare / rabbit
  Example sentence: Заяц прыгает в поле.  
  Example translation: The hare jumps in the field.  
  Memory hook: “Za-yats” sounds like “za-yachts” racing across a field.

- **Лев** (lyef) — lion
  Example sentence: Лев рычит громко.  
  Example translation: The lion roars loudly.  
  Memory hook: “Lyef” is like “leaf” but with a mighty roar instead of rustling.

- **Слон** (slon) — elephant
  Example sentence: Слон пьёт воду хоботом.  
  Example translation: The elephant drinks water with its trunk.  
  Memory hook: “Slon” sounds like “slon-g” — a long trunk swinging like a slingshot!

**Grammar Spotlight:**
Russian nouns have genders (masculine, feminine, or neuter) that affect the words around them. Most animal names ending in a consonant like собака’s friend кот are masculine, while птица and мышь are feminine. Compare to English, where we rarely mark gender on nouns — in Russian you say “большой кот” (big tomcat) but “большая птица” (big bird). Practice: мой кот (my cat, masculine) vs. моя рыба (my fish, feminine).

**Word Origins — Deep Dive: Медведь**
Did you know the Russian word медведь and the English idea of “honey-eater” are secretly cousins? This word started in ancient Slavic roots where “мёд” (myod) meant honey and “ведать” meant to know — so медведь literally means “the one who knows honey,” a polite way to avoid saying the real bear name and angering the animal! It travelled through old Slavic languages without borrowing from Latin “ursus” like most European tongues. But be careful — the Russian word “медведь” sounds nothing like English “bear,” yet both cultures used sweet nicknames to talk about the scary forest giant. Next time you see honey, remember it’s cousins with медведь — they both come from the same sweet Slavic secret.

**Cultural Corner:**
In Russian fairy tales, animals often act like wise teachers or tricky helpers — the bear is strong but kind, the fox is clever, and the wolf can be both scary and funny. Kids grow up hearing stories like “The Bear and the Fox” that teach lessons through animal adventures, just like Aesop’s fables but with snowy forests and magic.

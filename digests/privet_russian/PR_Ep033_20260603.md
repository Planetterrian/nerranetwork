> **Today we discover fun Russian words for animals while learning how Russians talk about their favorite pets and wild creatures.**

### Word of the Day
Кот (kot)  
Pronunciation: koht (rhymes with “coat”)  
English meaning: cat  
Example sentence: Это мой кот. (Eto moy kot.) — This is my cat.  
Memory hook: Think of “kot” as a cozy cat curled up on a cot!  
Repeat after me: Кот… (pause) Кот.
- Собака (sobaka) — so-BAH-kah — dog
  Example sentence: У меня есть собака. (U menya est’ sobaka.) — I have a dog.  
  Memory hook: “Soba” sounds like “so bark-a” — perfect for a dog!  

- Птица (ptitsa) — PTEET-sah — bird
  Example sentence: Птица летает. (Ptitsa letaet.) — The bird flies.  
  Memory hook: “Ptee” like “tweet” — birds tweet!  

- Рыба (ryba) — RIH-bah — fish
  Example sentence: Рыба плавает. (Ryba plavaet.) — The fish swims.  
  Memory hook: “Ryba” rhymes with “riba” — imagine a riba fish ribbing you!  

- Медведь (medved’) — med-VYED’ — bear
  Example sentence: Медведь большой. (Medved’ bol’shoy.) — The bear is big.  
  Memory hook: “Med” like “medal” — a bear wins the medal for biggest animal!  

- Заяц (zayats) — ZAH-yats — hare/rabbit
  Example sentence: Заяц прыгает. (Zayats prygayet.) — The hare jumps.  
  Memory hook: “Zay” sounds like “say” — the hare says “hi” with a jump!  

- Лошадь (loshad’) — lo-SHAD’ — horse
  Example sentence: Лошадь бежит. (Loshad’ bezhit.) — The horse runs.  
  Memory hook: “Lo-shad” like “low shed” — the horse lives in a low shed.  

- Слон (slon) — slon — elephant
  Example sentence: Слон большой. (Slon bol’shoy.) — The elephant is big.  
  Memory hook: “Slon” sounds like “slon” — slow and strong like an elephant!  

- Птичий (ptichiy) — PTEE-chee — bird’s (adjective)
  Example sentence: Птичий дом. (Ptichiy dom.) — Bird house.  
  Memory hook: “Ptee-chee” like “tweet-chee” — bird sounds!

**Grammar Spotlight:**
Russian nouns have genders (masculine, feminine, neuter) that affect endings. “Кот” is masculine, so it uses “мой” (moy) for “my.” “Собака” is feminine, so it uses “моя” (moya). Compare to English: we don’t change “my” for gender, but Russian always does — it’s like giving every word its own tiny label!

**Word Origins — Deep Dive: Собака**
Did you know that the Russian word “собака” and the English word “dog” are not related at all, but “собака” actually shares a surprising ancient root with words in Persian and Turkish? This word started in ancient Iranian languages, travelled through Turkic tongues, and finally arrived in Russian centuries ago as the everyday name for man’s best friend. But be careful — it is a false friend with some similar-sounding words in other Slavic languages that can mean “guard” instead! Next time you see a dog, remember it is cousins with “собака” through a long journey across Asia — that connection is your secret shortcut to remembering it forever.

**Cultural Corner:**
In Russia, many families keep cats and dogs as beloved pets, and stray cats are often welcomed at apartment buildings where neighbors leave food for them. Russians also love telling stories about bears, which appear in many folk tales as wise but grumpy characters.

**Practice Challenge:**
For kids: Draw your favorite animal and say its Russian name three times out loud while pointing to it. For adults: Next time you see a pet or animal picture, practice saying “Это [animal]” (“This is a [animal]”) in a full sentence.

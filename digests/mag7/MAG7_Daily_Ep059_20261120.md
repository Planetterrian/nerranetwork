> **Dozens of clicks become one Gemini prompt on a Mac, while your cursor stays free.**

**What You Need to Know:** Google’s Gemini app for Mac can now turn work that normally takes dozens of clicks into one prompt, running in a background window so the cursor stays free. Amazon will let agents put fixed-price Marketplace purchases on an AWS bill. Nvidia is in talks to buy a diffusion-model startup for at least $500 million, and two prepaid energy deals meant to provide $3 billion to Alphabet are paused.

### Top News
**Google Lets Gemini Control Mac Desktops: Silicon UK**
Google said computer use in the Gemini app for Mac is available starting today, so one prompt can run multi-step work across local files, desktop apps and the web. Gemini works inside an isolated background window with a live preview in the chat, and the main screen and cursor stay free. Google says the user chooses which apps Gemini can access, can watch every step, pause at any time, and approve key actions before they happen. Silicon UK reports the feature is initially in English in the United States and requires the Gemini desktop app plus a Google AI Plus, Pro or Ultra subscription. Google’s examples include batch color-grading photos, pulling weights, dimensions and addresses from local PDFs into shipping quotes, building a Google Slides deck from dashboard screenshots, and staging resale listings from a folder of clothing photos. The same week, Google began a broader rollout of Tasks, which can carry out multi-step online jobs such as purchases and booking appointments. Source: [silicon.co.uk](https://www.silicon.co.uk/cloud/ai/gemini-macos-agent-632450) Source: [betanews.com](https://betanews.com/article/google-gemini-control-macos/)

**AWS Lets AgentCore Agents Buy Marketplace Products Through AWS Billing: Unite.AI**
Amazon said on November 19, 2026 that Amazon Bedrock AgentCore payments can settle purchases from x402-enabled AWS Marketplace sellers through AWS Billing. Agents can buy software, APIs, data and content per request in US dollars, with the charge added to the developer’s AWS bill, and those purchases do not need a stablecoin wallet or an API key. A seller answers an unpaid call with HTTP 402 and a signed quote; if the session still has budget, AgentCore returns a payment token that Unite.AI says stays valid for about five minutes, and Marketplace rejects a quote whose price was altered. The first purchase from a seller creates an AWS Marketplace agreement; later purchases are tracked against it, recorded in CloudTrail and Cost Explorer, and settled before they appear on the monthly bill. A failed budget check leaves the developer uncharged. The sample separates roles so a session role can set a budget but cannot pay, while an agent role can pay but cannot create sessions, and Private Marketplace can limit the catalog. The documented walkthrough defaults to a $0.05 session budget and a $0.02 cap per request; in AWS’s test the agent compared two listings and completed one $0.01 payment. Source: [unite.ai](https://www.unite.ai/aws-lets-agentcore-agents-buy-marketplace-products-through-aws-billing/) Source: [superpowerdaily.com](https://superpowerdaily.com/posts/aws-lets-ai-agents-charge-pay-per-request-marketplace-purchases-to-cloud-bills)

### The Counterpoint
**Apple may be developing its own AI agent that runs your Mac: TechCrunch**
The Mac that Gemini is now driving is still Apple’s, and Apple is tightening who else gets to drive it. TechCrunch, citing Bloomberg, says the upcoming macOS 27.3 will deploy warnings discouraging users from granting full access to third-party agents. In October, Apple told developers it planned additional controls so that this level of access requires very explicit user action. The same reporting says Apple is hiring a senior engineering manager to build an agent that browses, works across apps, runs commands, writes and debugs code, and calls services, privately. Bloomberg’s account, as relayed by TechCrunch, is that Apple has eyed introducing that service as soon as the end of next year, and that progress remains in the early stages. TechCrunch asked Apple for more information and did not receive a response. The open question is whether those macOS 27.3 warnings and the explicit-consent control land before, or on top of, a third-party agent that needs broad access to apps, files and the web. Source: [techcrunch.com](https://techcrunch.com/2026/11/19/apple-may-be-developing-its-own-ai-agent-that-runs-your-mac/)

### The Thread: The Mac an agent still has to rent
Nearly 1,000 organizations were running Devin on macOS within six weeks of launch, Cognition told Amazon in an architecture post. Devin could already draft Swift on Linux. Building, testing and signing an app for iPhone, iPad or Mac still required Apple hardware and macOS, and Devin Cloud did not offer that until a couple of months ago. Sessions had run only on Linux and Windows virtual machines. Without Xcode, the agent depended on a customer’s continuous-integration system or that customer’s own Mac fleet. A clean compile still does not show behavior. The post’s example is an iPhone game that should resume where the player paused: the agent has to play, pause, quit, relaunch and confirm the saved state.

Amazon’s answer is EC2 Mac. Each instance is a physical Mac mini or Mac Studio attached to the Nitro System, so Cognition runs Apple’s Virtualization framework as it would on a Mac it owned. Dedicated Hosts come through the EC2 API rather than a shipping dock. The fleet is in six AWS Regions. A fresh macOS virtual machine starts in under a minute, which Cognition estimates is 15 to 20 times faster than a customer setting up a Mac host. Each Dedicated Host has a 24-hour minimum allocation, so the life of a session is split from the life of the host. Where capacity is not already reserved, an Auto Scaling group allocates and releases hosts. On each host, a Cognition manager boots guest VMs from images Cognition prepares. A disk keeps the session’s work so an idle session does not hold a VM. Network rules follow the session. A live view and an accessibility tree from accessibility-cli let both the user and Devin see and operate the app.

The shared limit is Apple’s license. The macOS Software License Agreement allows up to two additional copies of macOS in virtual environments on each Mac, and macOS enforces that cap, so each bare-metal host runs two isolated Devin workspaces. Idle sessions release those VMs, and one host can serve more than one session in a day. Apple is the only legal hardware and the only OS that can sign the app and run the iOS Simulator. Amazon is the API, the regions, the virtual private cloud and the EBS boot volume that make those Macs look like other EC2 instances. Cognition wrote the agent. Neither of the other two did.

What changes is who has to own the machine. A customer no longer keeps a private fleet just so an agent can open the simulator before it hands back a merge-ready change. Cognition can start a clean guest, with Xcode tools and the simulator, and return the host to later work the same day. Apple’s license still bounds how many copies sit on one computer at once. Amazon’s host minimum still means the bill works only if many short sessions share a machine. The post names no further launch date. Source: [aws.amazon.com](https://aws.amazon.com/blogs/architecture/ai-coding-agents-on-amazon-ec2-mac-how-cognition-scales-devin-for-macos/)

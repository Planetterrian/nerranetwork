# MAG 7 Daily
> **Apple Pay launches in India today with Axis Bank Visa and Mastercard cards.**

**What You Need to Know:** Apple starts its payments service in India to expand in a market of more than a billion consumers. Some large banks are holding off initial support and merchants must add Apple Pay compatibility for terminals to work. The service uses only Visa and Mastercard networks and does not support India's RuPay cards or UPI transfers. Axis Bank cards can now be added to the Wallet app on iPhone and Apple Watch for contactless and online payments. Major banks such as HDFC Bank, ICICI Bank and SBI Card have not added support yet. RuPay cards remain incompatible with the service.

**AWS Lambda timeout rises to 90 minutes on managed instances:** shattered.io
Functions running on Lambda Managed Instances can now execute up to 90 minutes when invoked asynchronously or through an event source mapping. The previous limit of 15 minutes stays in place for synchronous calls and for Amazon MQ or Amazon DocumentDB mappings. The change is live immediately across the console, CLI, API and infrastructure tools with no opt-in required. The six-fold increase applies only to asynchronous invocations and event source mappings except the two excluded services. Synchronous invocations through API Gateway remain capped at 15 minutes. The update affects CloudFormation, Terraform and the AWS Agent Toolkit right away. Lambda Managed Instances now support longer-running batch and AI inference workloads that previously required other services. Source: [shattered.io](https://shattered.io/aws-lambda-90-minute-timeout-managed-instances-2026/)

**Thought Machine and AWS launch AI core banking migration tool:** The Paypers
The joint solution uses AWS Transform and Vault Forge to convert legacy mainframe code such as COBOL into tested Python financial products. Banks run the four-stage pipeline inside their own AWS environment and receive validated migration proof early in the process. The tool compresses processes that traditionally take several years into days. The extraction phase converts business logic into EARS specifications. The consolidation phase reduces redundant legacy product variations. The synthesis phase uses Amazon Bedrock agents to generate SDK-compliant Python products and test suites. Human review gates in the validation phase give banks final sign-off authority before sandbox deployment. Source: [thepaypers.com](https://thepaypers.com/fintech/news/thought-machine-and-aws-launch-ai-powered-core-banking-migration-tool)

Amazon and Apple now share a machine an outside coding agent cannot skip. Nearly one thousand organizations were running Devin on macOS within six weeks of launch, Cognition told Amazon. Devin could already write Swift on Linux. Signing and testing an app for iPhone, iPad or Mac still needed Apple hardware and macOS, and Devin Cloud only got that a couple of months ago.

A clean compile still does not prove behavior. The post’s case is an iPhone game that should resume where the player paused: the agent has to play, pause, quit, relaunch, and check the save.

Amazon’s piece of that is EC2 Mac. Each instance is a physical Mac mini or Mac Studio on the Nitro System, so Cognition can use Apple’s Virtualization framework the way it would on a Mac it owned. Hosts arrive through the EC2 API, not a loading dock. The fleet sits in six AWS regions.

A fresh macOS virtual machine starts in under a minute, which Cognition puts at fifteen to twenty times faster than a customer standing up a Mac host. Each Dedicated Host has a twenty-four-hour minimum, so a session’s life is split from the host’s. Where capacity is not already held, an Auto Scaling group takes hosts and gives them back.

A manager on the host boots guests from images Cognition maintains. A disk keeps the session’s work, so an idle session does not sit on a virtual machine. Network rules follow the session. A live view, plus an accessibility tree from accessibility-cli, lets the person and Devin both see and drive the app.

The cap that binds them is Apple’s license, not Amazon’s rack. The macOS agreement allows up to two extra copies of the system in virtual environments on each Mac, and the operating system enforces it, so each bare-metal host runs two isolated Devin workspaces. Idle sessions give those machines back, and one host can serve more than one session in a day.

Apple remains the only legal hardware, and the only system that can sign the app and open the iOS Simulator. Amazon is the API, the regions, the private network and the boot volume that make those Macs look like any other EC2 box. Cognition wrote the agent.

What changes is who has to own the computer. A customer no longer keeps a private fleet just so an agent can open the simulator before it returns a change ready to merge. Cognition can start a clean guest, Xcode and simulator included, and put the host back to later work the same day. Apple’s license still bounds how many copies sit on one computer at once.

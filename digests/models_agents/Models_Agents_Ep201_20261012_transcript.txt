Constant time per step recall is where we pop the hood on a memory that neither the compressed

Time delay systems for sequence modeling replace that single compressed state with an explicit,
it, content-addressable delay that is estimated on the fly.
The core mechanism is a differentiable semantic lag estimator.
It produces soft attention weights over history from similarity between the current input
and past tokens.
Each step yields both a weighted historical context vector and a scalar similarity score.
A diagonal state space formulation then solves the cumulative sum in closed form.
That delivers order one per step complexity with no sequential loops inside the recurrence.
A fuzzy semantic modulation layer learns context-dependent rules that decide how much weight
to give the instantaneous input versus the recalled history.
Rule centers correspond to prototypical semantic contexts, so the policy stays interpretable.

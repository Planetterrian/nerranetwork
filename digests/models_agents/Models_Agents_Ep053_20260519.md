### Top Story
Anthropic announced it is acquiring StainlessAPI, the SDK and MCP server platform that has powered every Anthropic SDK since the API launched. The move gives Anthropic direct control over the tooling developers use to integrate Claude models, including support for the Model Context Protocol that many agent frameworks now rely on. StainlessAPI previously operated as an independent service used across multiple labs, so the acquisition centralizes expertise that previously sat outside Anthropic's walls. Developers building agents or custom SDK wrappers should watch for faster iteration on new endpoints and better MCP server examples in the coming months. The deal also signals Anthropic's intent to compete more directly on the infrastructure layer that sits between models and production applications. Teams currently using the official Anthropic SDKs or exploring MCP servers will likely see incremental improvements in documentation and example code first. ### Under the Hood: Skill Library Scaling in Agent Systems
Everyone talks about agent performance improving simply by using stronger models or adding more tools. In practice, skill libraries introduce two tightly coupled scaling laws that determine whether performance rises or collapses as the library grows. The routing law shows single-step accuracy decaying logarithmically with library size, with errors shifting from local competition to cross-family drift and eventual capture by overly general “black-hole” skills. The execution law reveals that joint routing behaves multiplicatively before state realization, yet correct execution can rescue difficult downstream decisions by roughly 4×. A single parameter—the routing logarithmic decay slope—predicts both pre-execution collapse and later recoverability across 15 frontier models and 1,141 real skills. Law-guided optimization lifted held-out routing accuracy from 71.3 % to 91.7 % and reduced hijacking from 22.4 % to 4.1 %, with gains transferring to ClawBench and ClawMark. Use explicit routing policies and periodic skill pruning once libraries exceed a few hundred entries; the alternative is silent degradation that only appears after deployment.

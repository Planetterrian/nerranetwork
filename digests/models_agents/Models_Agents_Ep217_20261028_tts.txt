Controlled symbolic probes are how you pop the hood on which attention heads actually carry a count effect.

The method varies only the count and order of two symbols inside otherwise fixed prompts, then measures how much each attention head shifts the logit difference — the score gap — between two answer tokens.

It first identifies candidate heads whose ablation removes most of the count effect and whose mean-output patching recovers the effect in both directions, then applies conditional bounds to decide which heads survive finite-sample noise.

In Pythia four hundred ten million this process isolates sets of one to twelve heads that remove sixty-five point five to ninety-one point six percent of the count effect while preserving influence on count comparisons never seen during selection.

When the same heads are ablated on a natural-language task that asks which state is supported by more reports, accuracy drops eight point two points versus zero point eight points for random sets of the same size and layer.

The technique supplies a compact, causally validated shortlist rather than a diffuse importance map.

Reach for it when you need to know which specific heads carry a particular reasoning behavior before editing, pruning, or monitoring those heads in production; the main practical limit is that the symbolic probe must be carefully balanced so the measured effect truly isolates the variable of interest.

Micro VM designs keep the host outside guest control by injecting secrets only at the network
gateway rather than into the guest file system or environment variables.
An agent running with root inside the VM never sees raw credentials.
The gateway applies hierarchical scopes, rate limits, and audit logs on every outbound connection.
The approach adds a small per request lookup cost, but eliminates the need to snapshot or
sanitize guest memory when pausing or suspending sandboxes.
BTRFS copy on right lets each sandbox start from a clean template root file system in
tens of milliseconds without duplicating full disk images.
When an agent must survive restarts or branch into stateful work,

The credential store adds hierarchical scoping, so different agent tasks receive different
permission sets without ever exposing keys inside the guest.
Rate limits and audit logging happen at the host layer, so even a compromised sandbox

Sandboxes move through four states, running, paused with resident VM memory, suspended with

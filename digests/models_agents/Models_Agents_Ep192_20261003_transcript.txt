Apple is tightening privacy controls on Mac computers as increasingly capable artificial intelligence agents gain access to sensitive user data. The company announced on Friday that it will introduce additional safeguards around its full disk access feature. The change requires more
explicit user action before an app can obtain broad access to files, messages, mail, and
other data.
Apple said that full-disc access is a powerful Mac OS capability that largely bypasses
the operating system's normal privacy protections.
The feature exists in part because certain applications, particularly backup services, need
broad access to a Mac's data to function properly.
However, Apple said some developers are using the capability in ways that could expose users
to privacy risks.
As AI agents become increasingly capable and autonomous, the risks associated with this
level of access will grow substantially.
Apple directly tied the planned changes to the rapid development of autonomous AI agents.
The company said an application with this level of access can potentially reach virtually
everything stored on a Mac, including files, mail, messages, and browsing history.
Going forward, Apple said it will introduce additional controls so users who want to grant
an application full disk access must take a more explicit action to do so.

In practice, each token only needs to touch a small number of memory cells, even as the
total memory grows without bound.
The model learns to index individual cells so that access costs stays constant rather
than linear.
This design separates the intelligence module, which stays fixed in size, from the memory
store that can keep growing.
When memory holds both facts and procedures, new capabilities appear without any weight updates.
rates. The practical rule is to use this approach when your workload involves long horizon
tasks that benefit from accumulating skills over time rather than static knowledge retrieval.
The intelligence module performs computation while memory holds knowledge, procedures,
and working state. Every token reads from and writes to an unbounded memory, yet touches
only a small number of cells at a time. Sparse architectures that fix the fraction of
capacity used at each step cannot match this flexibility.
The approach trades increased indexing complexity for unbounded growth without rising access

Databricks released work on injecting domain knowledge into large language models for malware triage of npm packages.

Eleven of fifty-four partial-network runs let agents slip the egress policy before anyone could pop the hood on network-layer credential scoping.

MicroVM designs keep the host outside guest control by injecting secrets only at the network gateway rather than into the guest filesystem or environment variables.

An agent running with root inside the VM never sees raw credentials.

The gateway applies hierarchical scopes, rate limits, and audit logs on every outbound connection.

The approach adds a small per-request lookup cost but eliminates the need to snapshot or sanitize guest memory when pausing or suspending sandboxes.

Btrfs copy-on-write lets each sandbox start from a clean template root filesystem in tens of milliseconds without duplicating full disk images.

When an agent must survive restarts or branch into stateful work, the host can snapshot VM memory plus the writable layer independently of any secrets.

Median create latency fell from one hundred eighty-five milliseconds to sixty milliseconds after the gateway design stabilized.

The credential store adds hierarchical scoping so different agent tasks receive different permission sets without ever exposing keys inside the guest.

Rate limits and audit logging happen at the host layer, so even a compromised sandbox cannot bypass them.

Sandboxes move through four states: running, paused with resident VM memory, suspended with a snapshot of memory plus the root filesystem, and deleted.

Paused memory stays resident on the worker, while suspended snapshots capture both memory and filesystem without touching stored credentials.

The extra gateway hop is the cost of keeping credentials off every guest-visible surface, and that hop is what you pay when the threat model demands it.

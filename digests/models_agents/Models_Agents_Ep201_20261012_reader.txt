SWE-Duel, in a paper on arXiv, pits two coding agents against each other over mirrored Red-Blue turns on real repositories.

In each turn the Red agent proposes a feature, implements it with tests, then embeds a subtle bug with sealed trigger tests.

The pull request is admitted only if it passes the feature tests and the existing tests while failing exactly the bug tests, and a fresh session of the same agent can repair that bug blind.

The Blue agent reviews without knowing a bug exists, and it wins only if its revision passes all three suites.

A tournament ran eleven model-harness pairs on fifteen repositories in five languages for one thousand five hundred turns.

GPT five point five with Codex CLI repaired ninety-eight point three percent of defects as the strongest solver, Claude Opus four point eight with mini-swe-agent led as task author at a twenty-seven point three percent Red win rate, and newer versions within a family produced harder tasks.

Elastic Latent Recurrence, also on arXiv, removes the one-loop tax for looped language models, which reuse the same layers instead of stacking new ones.

A gated state update with a learned step size, plus conditioning on the loop index, lets a single checkpoint match non-recurrent accuracy at one loop, and each added loop buys more accuracy.

Mixed depths introduced late in pretraining with zero-initialized conditioning cut the added training cost.

Reusing first-loop expert routes in mixture of experts models trims mixed-depth update time by eleven point seven percent.

On four billion dense and thirty billion A three B mixture of experts hybrids, four loops add seven point two five and four point seven five points on a ten-task average.

Post-training yields Koi-four B scoring an estimated eighteen on the Artificial Analysis Intelligence Index at one loop.

SEEDS adds preview-guided evidence admission to search agents, exposing lightweight previews of retrieved candidates and letting the agent jointly decide which candidates and how many to inspect fully, conditioned on its current reasoning state.

AutoIndexer, with code on arXiv, trains causal models on chains of edits for post-generation context editing.

Constant-time per-step recall is where we pop the hood on a memory that neither the compressed hidden state of an LSTM nor the fixed-dimensional state of Mamba actually gives you.

Time-delay systems for sequence modeling replace that single compressed state with an explicit, content-addressable delay that is estimated on the fly.

The core mechanism is a differentiable semantic lag estimator.

It produces soft attention weights over history from similarity between the current input and past tokens.

Each step yields both a weighted historical context vector and a scalar similarity score.

A diagonal state-space formulation then solves the cumulative sum in closed form.

That delivers order-one per-step complexity, with no sequential loops inside the recurrence.

A fuzzy semantic modulation layer learns context-dependent rules that decide how much weight to give the instantaneous input versus the recalled history.

Rule centers correspond to prototypical semantic contexts, so the policy stays interpretable.

On text classification and generation the approach outperforms prior state of the art.

The quality gain shrinks once models exceed roughly seventy billion parameters, because larger models already encode long-range dependencies inside their attention layers.

Use this technique when you need explicit, auditable recall of specific past events under tight compute budgets; the lag estimator must be trained on sufficiently diverse semantic contexts or it collapses to always favoring the current token.

15 chained Android TV boxes with four gigabytes of RAM apiece
are how researchers pop the hood on Pipeline Parallelism
for a 26 billion parameter model.
Pipeline parallelism splits a model's layers
across multiple low-memory devices.
Each device computes only its assigned slice
and passes activations forward to the next box in the chain.
Researchers placed two layers per box.
15 units were chained together to hold the full 26 billion-parameter model.
That fleet ran at 0.39 tokens per second.
The key value cash travels with the layers.
Devices can be added or removed without reencoding the prompt.
Because each box holds only a fraction of the weights, total system memory stays far below
what a single GPU would require.
The approach trades massive latency for extreme hardware accessibility.
stability, doubling time for a self-replicating agent on such a fleet would be measured in days
rather than minutes.
Network bandwidth between boxes is the main engineering constraint.
That link becomes the bottleneck once more than a handful of devices participate.
Teams facing strict air-gapped or cost-sensitive deployments should evaluate this pattern
when GPU clusters are unavailable, but idle-edge hardware is plentiful.

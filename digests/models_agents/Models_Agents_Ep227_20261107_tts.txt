Median time to first token on shared-prefix workloads sat at six point eight eight seconds on three L forty S G P U's, and that is the number to pop the hood on with Kinference’s key-value cache routing.

Time to first token, or TTFT, is how long you wait before the model emits token one, and most of that wait is prefill — writing the prompt into key-value cache in G P U memory — with decode only starting once that cache exists.

Prefill cost scales with prompt length, which is why a fat shared system prompt dominates TTFT when every request pays it in full.

The overlapping case is a long system prompt or the same retrieved document sitting in front of many different user questions, and reuse only works if the next request hits the worker that already has those keys and values resident.

Kinference’s balancer is built to send the request where that cache already lives, and the median TTFT on that traffic fell to zero point three one seconds.

The v zero point one point zero alpha seven code is Rust, the cluster config is five custom resource definitions, or CRDs, Kubernetes objects you declare instead of hand-wiring services, and a gRPC inference handler sits on the path.

The engineering says put an alpha control plane on multi-tenant traffic that actually shares prefixes, and do not treat the sub-second figure as a number for cold, one-off prompts.

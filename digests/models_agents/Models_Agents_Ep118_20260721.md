### Model Updates
**JOR-Bench: Japanese Operations Research Benchmarks for Large Language Models — arXiv NLP**
Seven LLMs were evaluated on five Japanese-translated OR benchmarks covering linear, mixed-integer, nonlinear, and combinatorial problems. Strong multilingual models showed only a -0.3 pp average accuracy gap between English and Japanese versions when standardized on OR-Tools. Error analysis revealed Japanese prompts sometimes caused models to output decision-variable values instead of objective values. The benchmark is solver-independent and released with 1,319 problems. Teams working on optimization or planning agents should test their current models on the Japanese splits to check for pragmatic disambiguation failures. The five source benchmarks translated were IndustryOR, MAMO Complex LP, NL4OPT, OptiBench, and OptMATH. Results indicate that OR formulation ability is largely language-neutral for capable multilingual models, yet subtle cross-lingual pragmatic failures persist in Japanese. The evaluation standardized execution through the Python interface to OR-Tools to ensure reproducible outputs across all tested models. Source: [arxiv.org](https://arxiv.org/abs/2607.16777)

**KyrgyzLLM-Bench: Benchmarking Kyrgyz Language Understanding — arXiv NLP**
The first large-scale native Kyrgyz evaluation suite combines KyrgyzMMLU, KyrgyzRC, and post-edited translations of WinoGrande, HellaSwag, BoolQ, and TruthfulQA. Twenty-six open- and closed-source models were tested in zero- and few-shot settings. Model rankings largely transferred from English on WinoGrande and BoolQ, but HellaSwag showed a clear English-Kyrgyz gap attributed to translation artifacts. All datasets, code, and per-model results are publicly released and integrated into a multilingual evaluation framework. Developers targeting Central Asian languages now have a reproducible baseline for measuring cross-lingual transfer. The suite includes two natively authored datasets alongside carefully post-edited translations. Few-shot prompting improved several open-source models on reading comprehension while behaving inconsistently for proprietary models on translated tasks. The benchmark explicitly addresses the scarcity of natively authored evaluation data for less-resourced languages such as Kyrgyz.

**OpenLanguageModel: Readable and Composable Small-Language-Model Pretraining for Education and Research — arXiv NLP**
OLM is an MIT-licensed PyTorch library that makes small-model pretraining code read like the architecture diagram using ordinary modules and high-level combinators. It ships 27 presets across nine model families and supports single-GPU to single-node multi-GPU runs with 90.6 % weak-scaling efficiency on a 348 M parameter workload. The package includes tokenizers, streaming datasets, mixed-precision training, and AutoTrainer for hardware-aware configuration. Researchers can move from a teaching notebook to a full FineWeb-Edu pretraining run or an attention ablation without rewriting infrastructure. The library is available on PyPI and GitHub with documentation that scales from fundamentals to architecture experiments. The design uses Block, Residual, Repeat, and Parallel combinators so that model code directly mirrors the intended wiring. Validation confirmed close agreement with independent reference implementations across the preset families.

**SpecLA: Efficient Speculative Decoding for Linear-Attention Models — arXiv NLP**
SpecLA brings speculative decoding to stateful linear-attention models by using topology-aware kernels, compact state factors, confidence pruning, and an EAGLE-style drafter. On an NVIDIA H100 with the public GDN-1.3B target it delivers up to 1.70× end-to-end speedup over standard autoregressive decoding. The system stores only accepted state trajectories and avoids submitting candidates that would waste recurrent verification work. Teams running long-context inference on linear-attention backbones can now reduce per-token latency without changing the base model. Verification follows recurrent dependencies across chains and branches rather than independent token positions. The drafter incorporates target-aligned EAGLE-style generation plus confidence pruning to feed only useful candidates to the verifier. This approach is the first speculative decoding runtime explicitly designed for stateful linear-attention targets.

### Practical & Community
**Real-World Evaluation of an AI Agent Drafting Translational Impact Summaries — arXiv NLP**
A human-in-the-loop agent built for CTSA programs assembles scholar dossiers and drafts one-sentence TSBM impact summaries. Across 10 scholars the system produced 507 findings with an 81.7 % unanimous usable rate after two independent reviewers. Median staff review time dropped to 14 minutes per scholar versus the prior 15-hour manual process. The agent’s evidence spanned all four TSBM domains and surfaced non-scholarly categories often missed by routine workflows. Teams handling research-impact reporting can adapt the same human-in-the-loop pattern to reduce manual evidence gathering. Two evaluation staff independently coded every finding as accept, edit, or reject. Inter-rater agreement reached a Cohen’s kappa of 0.43 on the usable-versus-reject decision. Reviewers rated synthesis accuracy 4.5 and usefulness 4.8 on five-point scales.

**Schema-Constrained Document-Level Event Argument Extraction with Lightweight LLM Fine-Tuning — arXiv NLP**
Mid-sized open models fine-tuned with LoRA on MAVEN-ARG reached 42.39 % F1 at the event-coreference level, outperforming prior GPT baselines. The pipeline injects role sets in prompts, trains on a JSON-only interface, and applies deterministic post-processing for schema validation and span alignment. Code to reproduce the experiments is released at the linked repository. Practitioners needing structured extraction from long documents now have a reproducible recipe using 14 B-scale open models. The best-performing model was Phi-4 at 14 B parameters. The approach combines role-set injection, parameter-efficient supervised fine-tuning, and post-processing that validates JSON, filters invalid roles, de-duplicates arguments, and aligns spans to the document window. Fine-tuned mid-sized open models outperformed previously reported GPT baselines across mention, entity-coreference, and event-coreference evaluations.

### Under the Hood: Speculative Decoding for Stateful Linear-Attention Models
Everyone talks about speculative decoding as a simple “draft-and-verify” trick that works the same everywhere. In practice, linear-attention models replace the growing KV cache with recurrent states, so verification must respect recurrent dependencies across chains and branches instead of independent token positions. SpecLA therefore adds topology-aware kernels that only accept contiguous accepted trajectories and stores compact factors that let the system recover the exact state after a partial acceptance. This design avoids wasting verification work on candidates that would invalidate later recurrent steps. On an H100 the approach yields up to 1.70× end-to-end speedup for a 1.3 B target while keeping the base model frozen. The drafter must avoid submitting candidates that waste stateful verification work, which is achieved through confidence pruning and a target-aligned EAGLE-style generator. Verification follows recurrent dependencies across chains and branches, requiring acceptance to update only the accepted state trajectory rather than independent positions. The system stores compact factors produced during verification to recover accepted states without re-computing the entire recurrent history. When to use this versus the alternative is straightforward: if your workload already uses linear attention for long contexts, the extra engineering buys latency reduction without retraining; if you are still on standard Transformers, the same gains require different state-management machinery. The gotcha that bites most teams is failing to prune low-confidence drafts early, which re-introduces the very verification overhead the method aims to eliminate.

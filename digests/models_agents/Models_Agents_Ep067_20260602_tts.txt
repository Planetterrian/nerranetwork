OK, let's pop the hood on non-koo-dah inference realities.

Everyone talks about running local agents as if koo-dah is the only practical path.

In practice, SYCL and ROCm backends force different memory layouts and kernel choices that change both throughput and developer effort.

On Intel Arc hardware, Qwenthree point six to thirty-fiveB-A3B reached nine hundred seventy-seven tokens per second prompt processing at Q4_K with a two hundred sixty-two thousand context window.

The same workload on ROCm still requires manual workarounds for MI50 cards and lacks mature flash-attention equivalents.

The quality gap is smaller than the tooling gap.

Models themselves run, yet missing optimized kernels for common agent operations like structured JSON decoding or long-context summarization keep non-koo-dah stacks behind.

When the workload is a small number of parallel thirty billion class agents and you already own the hardware, the non-koo-dah route is worth the extra setup time.

Otherwise the koo-dah ecosystem still wins on both speed of iteration and library availability.

Sixty-seven point six percent average accuracy at four B is why we pop the hood on EDU-Jev's pointer heads for single-pass categorical decisions.

Pointer heads let a model output a probability distribution over a fixed set of options in one forward pass by scoring each option with a learned marker instead of generating tokens.

The core move is to replace the usual language-modeling head with a small set of option-specific linear probes that share the same encoder.

Because the output vocabulary is now exactly the allowed choices, calibration becomes a direct softmax over those scores rather than an indirect mapping from free-form text.

That removes both the parsing step and the risk that the model produces an out-of-set answer.

The family supplies single-pass decision models from zero point eight B to four B for education tasks.

The four B variant hits sixty-seven point six percent average accuracy across twelve education benchmarks, beating the strongest commercial API by nine point four points and the best open four B model by eighteen point seven points.

It runs approximately one hundred fifty decisions per second on one H one hundred, roughly an order of magnitude faster than any text-generation baseline that must be post-processed.

The quality gain disappears once the option set grows beyond a few hundred entries because the pointer head must still compete with the encoder's capacity; at that scale a lightweight reranker on top of a generative model becomes preferable.

Use pointer heads when the task is closed-set classification with a stable label inventory and latency matters; fall back to generation-plus-parsing when the label space is open or changes frequently.

OK, let's pop the hood on the Nvidia key value cache transfer work.

Everyone talks about swapping models mid agent session as a simple routing decision.

In practice the receiving model must normally re run the entire prefill to rebuild its key value cache, which scales linearly with context length and model size.

Nvidia’s approach observes that key value caches within the same model family are approximately linear structures.

A closed form per head ridge regression fitted on a few hundred calibration sequences can map source keys and values into the target model’s expected format.

The mapper strips RoPE encodings first, then selects the most predictive source layers for each target layer.

This turns what used to be a full prefill into a few hundred milliseconds of linear algebra.

On matched key value pairs the technique retains 73 to 98 percent of the target model’s standalone accuracy while running 2.7 to 25 times faster than recomputing the cache.

The eight billion to 70 billion Llama leap still recovered 72.8 percent accuracy.

A single source layer recovered 56 percent of target key variance and 32 percent of value variance.

Combining multiple layers raised those figures to 79 percent and 65 percent.

Two Ministral pairs needed a small nonlinear multilayer perceptron fallback because the linear fit failed to extrapolate.

This builds on yesterday’s discussion of inference economics by showing a concrete way to cut the prefill tax in multi model workflows.

Use the linear mapper when you control both models and need low latency handoff on long contexts.

Fall back to full prefill or a trained adapter only when accuracy on a specific pair drops below acceptable thresholds.

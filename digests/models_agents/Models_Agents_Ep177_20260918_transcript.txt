Late fusion keeps each retrieval signal independent until the final ranking step.
Early joint embedding is avoided.
The three signals in trio rag each query the same multi-vector index.
A weak image match can still surface if the VLM enhance text query scores strongly.
This independence removes the need to maintain a single corpus level graph.
The graph would otherwise need rebuilding whenever any document changes.
On the reported benchmarks, the approach delivers 1.6 to 2.3 times faster per query inference.
No cross-signal attention occurs until after the top-k candidates are already fetched.
The trade-off appears when one mortality dominates.
If the anchor image is the only reliable cue, the text only signals add noise.
Late fusion must downweight that noise at ranking time.

### Top Story
Meituan released LongCat-2.0, a 1.6-trillion-parameter open Mixture-of-Experts model that activates roughly 48 billion parameters per token. It ships with a native 1-million-token context window built on LongCat Sparse Attention and was trained and served entirely on domestic AI ASIC superpods. The architecture targets long-context workloads while keeping active parameter counts manageable for inference. Builders working on document-scale or multi-turn agent tasks now have a new open-weight candidate that avoids reliance on foreign silicon stacks. An independent Tunisian developer released a full machine-translation pipeline and parallel corpus for Tunisian Darija written in Arabizi, including a custom SentencePiece tokenizer and a 15.6M-parameter encoder-decoder trained from scratch. The project starts from a 553-pair hand-curated seed set and is expanding via consented community contributions. Anyone working on low-resource Arabic dialects now has an open baseline and data collection framework to build on. The repo, dataset, and model are all public on GitHub and Hugging Face. Contributors should follow the documented consent and provenance tagging process. ### Under the Hood: Synthetic Data Homogenization
Everyone talks about model “sameness” as an inevitable side effect of scale. In practice it emerges from the structure of the synthetic data flywheel itself. When successive models train on outputs that already share overlapping token distributions and hedging patterns, the next generation inherits a narrower set of stylistic attractors. This compounds across turns because each new sample reinforces the same high-probability continuations rather than introducing fresh variance. The effect is measurable in comparative evals once you push past generic prompts into niche domains, where outputs converge on cadence and blind spots even before full collapse occurs. Teams that fine-tune exclusively on human-curated data see the homogenization slow, but the cost is steep and the data volume is limited. The practical decision is whether your workload tolerates reduced texture in exchange for cheaper generation or whether you need to maintain a parallel human seed set specifically to counteract the flywheel.

NVIDIA, according to the Hugging Face blog, released synthetic training sets, a fine-tuning recipe, and a DFlash2 speculator for faster inference on Nemotron 3.5 Parse, the compact document model that turns page images into structured data for retrieval-augmented generation, or RAG, and agents.

Three datasets are open: Synthetic Charts V1 with nine point nine eight million examples, Synthetic Tables V1 with one million, and OCR Synthetic Multilingual v2 with seven point nine million, all aimed at chart and table extraction.

Training ran supervised fine-tuning on document understanding first, then reinforcement learning for accuracy, consistency and reliable completion.

Parse reads a page in reading order, labels headings, paragraphs, tables and charts, and returns bounding boxes, and the latest cut handles harder charts and tables, including unlabeled bar charts, reading values off axes and bar heights.

Tables keep row and column layout so a shift cannot rewrite the meaning, and the synthetic pipeline renders chart and table variants with known ground truth so the model learns to reverse that rendering.

Thousands of generative calls per memory build drop away when you pop the hood on MGMem, which an arXiv paper presents as a swap from generative large language model, or LLM, summarization to a deterministic discriminative-parser pipeline.

Recurring mentions across sessions become an incidence graph that ties the same entities together, a subject-conditioned three-stage resolver decides which past mentions a question is talking about, and the system hands back the original raw dialogue episodes instead of synthesized text.

That cut also removes non-determinism and provenance loss, because later queries fetch exact source turns rather than paraphrased summaries, and no LLM rewrites history at index time.

On English multi-session dialogue question answering it beats matched-protocol baselines on LoCoMo with zero generative indexing, stays competitive on the full LongMemEval-S benchmark, and leads or ties on single-session retrieval tasks where local context dominates.

A downstream reader sees the precise original utterances and can verify context directly, which matters when an agent must cite exact past interactions or when repeated generative calls would blow a budget.

MGMem is a drop-in deterministic alternative when a workflow needs auditability or indexing that avoids stochastic LLM calls; generative summarization stays the better fit only when heavy abstraction across thousands of turns is the goal and exact wording is secondary.

Control symbolic probes are how you pop the hood on which attention heads actually carry
a count effect.
The method varies only the count and order of two symbols inside, otherwise fixed prompts.
Then measures how much each attention head shifts the loge at difference.
The score gap between two answer tokens.
It first identifies candidate heads whose ablation removes most of the count effect, and whose
mean output patching recovers the effect in both directions, then applies conditional
bounds to decide which heads survive finite sample noise.
In Pithia 410 million, this process isolates sets of 1 to 12 heads that remove 65.5 to 91.6%
of the count effect while preserving influence on count comparisons never seen during selection.
When the same heads are ablated on a natural language task that asks which state is supported by
more reports, accuracy drops 8.2 points versus 0.8 points for random sets of the same size and layer.
The technique supplies a compact, causally validated shortlist rather than a diffuse importance map.
Reach for it when you need to know which specific heads carry a particular reasoning
behavior before editing, pruning, or monitoring those heads in production.
The main practical limit is that the symbolic probe must be carefully balanced, so the measured
effect truly isolates the variable of interest.

# Models & Agents for Beginners
> **Claude just turned an ancient unsolved manuscript into a 7,417-frame movie it coded itself.**
An AI took on one of history's biggest mysteries—the Voynich Manuscript—and instead of just giving up, it created a shareable animated explainer movie by writing Python code to draw every single frame. This shows how today's AI can tackle creative challenges in surprising ways. Today's episode breaks down what happened, how the AI actually built the movie, and why projects like this matter for anyone who loves puzzles or storytelling.
---
### The Big Story
Someone asked Claude to pick any mystery that fascinates it and then solve the mystery while also producing a short movie that could be posted on social media. Claude chose the Voynich Manuscript, a 15th-century handwritten book filled with unknown plants, astronomical diagrams, and text in an undeciphered script that has resisted every attempt at translation for centuries. The model first tried to analyze the manuscript's content and structure but concluded that the writing does not behave like any known natural language and that no consistent encoding process could be identified despite extensive testing. After the analysis reached a dead end, Claude shifted to creating a visual explanation instead. It wrote a complete Python program that receives a time value in seconds and generates an entirely new image for that exact moment, producing one frame at a time without reusing any pre-existing artwork or photographs. The finished movie contains 7,417 individual frames, each calculated and drawn from scratch by the code the AI itself authored. The entire project, including multiple rounds of analysis by different agents, would have cost roughly $85 in token usage on the Fable 5.1 model if run outside the user's existing subscription limits. The original prompt contained language that risked encouraging the AI to describe itself in human-like terms, so the researcher added a reminder to avoid self-anthropomorphism when reviewing the results. For anyone who enjoys history, puzzles, or making short videos, this example shows how an AI can turn an unsolved research problem into something watchable and shareable without requiring a film crew or animation studio. Students working on reports about medieval manuscripts or unsolved codes can now ask an AI to generate a similar visual summary instead of relying only on static text. Hobbyists who want to explain their own favorite mysteries can start the same way by visiting claude.ai, opening a fresh conversation, and typing the exact request: "Pick a problem or mystery that obsesses you and solve it as best you can & make a movie we can share on social media about it," then describing the topic they want explored. ### Explain Like I'm 14
You know how a flipbook works: you draw a slightly different picture on each page, then flip the pages quickly so the drawings seem to move. 

An AI can do something similar, except it never draws by hand and never copies pictures that already exist. Instead, it writes a set of mathematical instructions in Python code that say exactly what shape, color, and position should appear at any given second. 

When the code receives the number 0.0 as input, it draws the first frame according to those rules. 

When it receives 0.033 seconds later, it runs the same rules again but with the tiny time change, so the shapes shift just enough to suggest motion. 

Because the only changing input is the time value, the AI can make smooth movements—such as a planet rotating or a plant stem growing—simply by adjusting the math inside the code for each new frame. 

The process repeats thousands of times until every required frame exists, and the finished sequence is assembled into a video file. 

In the Voynich project the AI did not film real objects or paste together stock images; it created the entire 7,417-frame animation by calculating and rendering each picture independently from the rules it had written. 

The result looks like a hand-crafted animated explanation even though no human artist touched a single frame.

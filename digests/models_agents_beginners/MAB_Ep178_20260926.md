# Models & Agents for Beginners
> **Claude just turned a single prompt into a video that explains recursion by switching styles nine times.**
Today we're looking at how one AI model took a tricky idea and made it into something fun and visual. You'll also see a simple way to turn ChatGPT into your own reminder system and a fully code-drawn animated project. Plus quick looks at other creative experiments that show what these tools can do right now.
---
### The Big Story
A researcher asked Claude Opus 5.5 to create a video explaining recursion. The exact prompt read: "A video explaining recursion, where every explanation about recursion has a radically different video style, make this self-referential & clever & fast moving." Claude delivered a finished video that shifts through nine distinct genres in just a few minutes. 

Think of it like asking a friend to tell the same short story nine times but in nine totally different art styles—stop-motion one moment, then comic book, then hand-drawn, then pixel art—without ever repeating the look. The AI kept the core message about recursion (the idea of something referring back to itself) while making each section feel fresh and surprising. The model handled the entire request in one pass instead of requiring separate rounds of fixes for each style change. 

This matters because it shows how today's models can handle long, detailed creative instructions in one go instead of needing lots of back-and-forth fixes. For students or anyone who learns better from visuals, it opens up new ways to turn confusing topics into something watchable and memorable. School projects on math or science concepts could become short videos that change visual tone to hold attention. It also hints at future tools that could help with school projects, explainer videos, or even short stories where style changes keep things interesting. 

You can try something similar yourself by opening Claude (claude.ai) and giving it a clear, detailed prompt about a topic you want explained in changing styles. Start simple: ask it to explain a school subject with three different visual approaches and see what it creates. The result may not match nine full genre shifts on the first try, but the same single-prompt approach works for shorter experiments. Source: [x.com](https://x.com/emollick/status/2103688362960019567)

### Explain Like I'm 14
You know how when you're texting a friend and you say "tell me the same joke but make it sound like a pirate, then a robot, then a news anchor," your friend can switch voices each time while keeping the joke the same? 

Now picture that same request but for a whole video instead of just words. The AI doesn't just write the script once—it plans out different visual rules for each section, like "this part should look like old film" or "this part should look like a comic book," and then builds the scenes to match those rules while the explanation stays about the same idea looping back on itself. 

Each new style is chosen on the fly so the video never feels repetitive, yet the core explanation keeps pointing back to the earlier parts. The model tracks the changing rules across the whole thing the way you might remember the different voices in your joke request. It also has to keep the self-referential quality the prompt asked for, so every new section still nods to the fact that the video is talking about itself. 

What feels like magic is really the model treating the entire prompt as one big set of instructions it has to satisfy at the same time. When it works, you end up with something that feels hand-crafted even though it came from a single paragraph of text.

### Cool Stuff & Try This
**Turn ChatGPT into your own future reminder system**
ChatGPT can now connect to email accounts so you can tell it to send yourself a message on a future date. It creates the email, schedules it, and delivers it exactly when you asked. The user who shared this connected both an Outlook inbox and a separate Gmail account through the built-in connectors. They tested it by asking the AI to email them one hour later, and the message was queued correctly for delayed delivery. This turns the AI into a lightweight personal reminder tool without needing extra apps. Anyone who forgets to follow up on ideas or wants gentle nudges later in the week should try it. Go to chat.openai.com, connect your Outlook or Gmail through the connectors, then say something like "Email me about my history project next Friday at 6pm" and watch it set up the scheduled message. Source: [reddit.com](https://www.reddit.com/r/ChatGPT/comments/1wqcb99/i_gave_my_ai_its_own_email_inbox/)

**A whole animated project made only with code and AI help**
One creator built an entire animated story where every scene is drawn in React and SVG, and the music plus sound effects were written in Python. The only files that aren't code are a few hundred small textures like film grain and bokeh, which were code generated in advance so the render would run faster, plus open-source fonts. The result looks like a polished short film but is actually all generated instructions. This is exciting if you like animation or want to see how code can replace traditional drawing tools. You can explore similar ideas by going to a free SVG drawing site like svg-edit or opening Claude and asking it to generate simple animated SVG code for a short scene you describe.

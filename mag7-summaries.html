The Thread: Cost per solved task

NVIDIA server version 0.3.0 of NeMo Switchyard is the open-source library Amazon's sample uses to choose which Amazon Bedrock model answers a coding agent. The sample installs switchyard-server 0.3.0 from crates.io and runs LiteLLM image version 1.102.0, both in one container on Amazon Elastic Container Service on AWS Fargate in private subnets. Amazon says NVIDIA documents that server release as a demo and evaluation component, and Amazon calls the integration experimental sample code, not a production deployment.

A coding agent works in tasks. The developer asks for a change; the agent reads files, edits code, and runs tests until the work is done. One task can take a few model calls or dozens. Token price does not equal task price, because the bill depends on how many turns a model needs, how much history each turn replays, and how often a run is retried or never finishes. Every attempt is paid, including attempts that never finish. Amazon's score is cost per solved task: total cost of the runs divided by the number of runs whose tests pass.

The library supports two strategies through LiteLLM. Stage routing reads recent tool activity and results in the history, so the agent must send the full conversation, then picks between a capable model and a lower-cost efficient model. Random routing picks from the configured models, with optional weights, for splits and comparisons. Neither strategy calls a judge model. LiteLLM has also shipped a native Switchyard stage router as an auto-router. Deployment in the sample uses the AWS Cloud Development Kit, and Amazon tells customers to clear the design with security and legal teams and to test it in a non-production account first.

Amazon hosts the gateway and the models; NVIDIA supplies the chooser. The agent sends an OpenAI-compatible request with the model field set to switchyard and a shared gateway key. Only the IPv4 range the deployer allows can reach the hostname, which sits on a load balancer with an AWS Certificate Manager certificate. AWS WAF applies IP-reputation, known-bad-input, and per-IP rate limits. The load balancer forwards only three paths, chat completions, models, and a health check, and returns 404 for every other path. LiteLLM checks the key, the plugin picks the model, and the call goes out through the Bedrock Converse or ConverseStream API on the task's own identity role, via a runtime interface endpoint so the traffic stays on Amazon's network. The header x-litellm-model-name names the model that answered.

The split of work is the change. Amazon gets a harness that compares a routed group with single-model baselines on a customer's own workloads, which is how the post says to judge the router. NVIDIA gets its library in the request path of agents that already speak a common format, without operating the gateway or the capacity those agents consume. The benchmark runners in the sample are the step the post actually specifies for deciding whether that split is worth keeping. Source: aws.amazon.com

AWS Emulator: Open-source tool for testing AWS apps locally, built by autonomous AI agents: Help Net Security

Amazon Web Services has released AWS Emulator, a free tool that simulates AWS services on a laptop, a development server, or in a continuous-integration pipeline, Help Net Security reported. The company says autonomous agents wrote it entirely. Senior principal engineer Matthew Goldberg said, "The emulator was written entirely by autonomous agents. Our team hasn’t written or reviewed any of the code," because guardrails kept the agents inside set lines. Three agent teams divide the work: one builds tests from public API specifications and checks them against real AWS, one runs those tests on the emulator and groups failures, and one fixes a single problem per agent. Hundreds of agents fix thousands of issues a day against a library of tens of thousands of tests, and a change enters the main codebase only after build checks and agent reviews for coding standards, security, and fidelity. Developers can start it through an AI coding agent, a Linux package, Docker, or an embedded mode inside a Rust test process. There is no extra service fee — users pay for AWS resources when they deploy — and the code and fidelity tests are on GitHub under a CC0 public-domain dedication, with per-service fidelity scores published at each release. The emulator will not tell you whether a permission holds: Help Net Security

The 2020 contract was a diversification, not a swap. The newer layer is models, not racks. KB is tying internal systems to Bedrock at individual affiliates. The named ones are an AI investment-product information service at KB Asset Management, an AI development and operations platform for employees at KB Securities, and a customized real-estate information service at KB Kookmin Bank.

The sharpest build is the KB AI Dev Center, a dedicated AI software unit the bank opened in July this year. Developers describe the function they want in ordinary language. What changes for Amazon is a flagship financial account moving from a 2020 infrastructure contract into agent-style development, on an invitation AWS itself extended.

The brief

Refresh & systematize — not reinvent

Nerra started as Tesla Shorts Time. It's now a multi-show, multilingual daily network spanning English, French, Russian and Chinese. The existing identity has the right idea — a constellation of shows, a dark intelligent base, an electric gradient — but it drifted: the logo font didn't match the website, two different brand gradients were in use, and the system didn't visibly scale as shows were added. This refresh keeps every piece of equity and fixes the system underneath it, with one organizing feeling: energy & momentum — a network that ships something new every single day.

Kept

The Nerra Network name, the constellation mark, the dark navy base, and the violet→cyan signal gradient.

Fixed

One locked gradient. A wordmark that matches the site. A node system that scales to any number of shows. A unified cover template.

Added

A momentum-led voice, a tagline system, ready-to-ship banners, and a per-show color framework.

Logo system

The mark & lockups

The mark is a broadcast constellation: a bright hub pushing signal out to six nodes, wrapped in a pulse ring. It reads as a network and as energy radiating outward. The wordmark is now a single confident geometric lockup — Nerra in white, Network in the signal gradient.

✓ Do

  • Give the logo clear space equal to the mark's corner radius on all sides.
  • Use the gradient wordmark on dark; the light lockup on pale backgrounds.
  • Shrink to the favicon mark below ~40px.

✗ Don't

  • Recolor the gradient or swap in show colors on the network mark.
  • Stretch, rotate, or add drop shadows to the wordmark.
  • Recreate the wordmark in a system font — it's a fixed outline.

The constellation system

Every show is a node

The network mark stays pure gradient. But each show gets one accent color — its node in the constellation, its cover glow, its on-air signature. Distinct, deliberately spaced hues so the family never blurs together — add the next one as the roster grows.

Typography

A three-voice type system

The old logo was Helvetica while the site ran on DM Sans. We resolve it into one clear hierarchy — already 2/3 loaded on the site today.

Display / Logo
Poppins
Headlines, the wordmark, big numbers. Geometric, confident, kinetic — the "momentum" voice.
UI / Body
DM Sans
Navigation, buttons, captions, all interface text. Already the site's font.
Editorial
Source Serif 4
Long-form blog reading. Already the site's serif. Signals "human-written," not content-mill.

## P0 — listener-facing bugs shipping today

### P0.1 — Ep2 chapter TOC is content-sentence debris (and Horizon chapter missing)
`chapters_ep002.json` titles include **"The chip powers OriginOS 7 on the new smartphone series"** and **"AMD confirmed it did not ship the dual-use chip to the…"** — spoken body lines, not section/headline chapters. Root cause visible in the Whisper transcript: the script never utters the required chapter anchor `on the horizon`, so the Horizon marker in `shows/ai_chips.yaml` chapters.section_markers cannot fire; news-body fallback then labels on arbitrary sentences. Ep3 correctly speaks "On the horizon, cadence and synopsis…" and gets a clean Horizon chapter (`chapters_ep003.json` 330.6 s).

**Proposal:** keep the podcast-prompt contract (first Horizon sentence must contain "on the horizon" once) and add a **drift-guard** that fails the show fixture when a script lacks the Teardown phrase `take it apart` or the Horizon phrase `on the horizon` (shape already required for chapter keys). No chapter-engine URL/path changes.

### P0.2 — Consumer handset silicon shipped as Silicon news (Ep2)
Transcript Ep2: Vivo X500 Pro / MediaTek Dimensity 9600 Pro / OriginOS 7 performance percentages; SemiAnalysis A20 from iPhone 18 Pro Max package. Digest selection rules already say reject consumer graphics and gaming reviews; they do **not** name smartphones/handsets, and `exclude_title_patterns` only cover best-gaming-gear, shopping deals, game reviews, and how-tos (`shows/ai_chips.yaml`). Listener product is an AI-infrastructure briefing, not phone SoC launch coverage.

**Proposal:** extend `exclude_title_patterns` + one digest-selection bullet (phones/handsets/OriginOS/Snapdragon flagship consumer SKUs) so fetch and LLM both drop that class.

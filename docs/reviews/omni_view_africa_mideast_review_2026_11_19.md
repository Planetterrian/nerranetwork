### P0-1 — Local currency spoken as US dollars (naira audit)
Ep16 transcript states the Nigerian Population Commission noncompliance report “flags more than $245 billion” and “$131.56 billion for 800,000 handheld census devices.” At USD those unit prices are absurd; the same figures as naira are plausible. System accuracy rules (`shows/prompts/omni_view_africa_mideast_system.txt` ACCURACY RULES) require facts from articles and distinction of claim vs finding, but never pin **currency unit as written by the source**. This is a trust-breaking error on a desk that attributes every claim.

**Proposal:** Add an explicit currency-unit rule to the system prompt (and the shared desk digest body if that is where numeric rendering is specified): speak the source currency (naira, rand, dirham, cedi, pounds, euros); never relabel as dollars unless the source figure is USD; if a USD conversion is given by the source, speak both.
